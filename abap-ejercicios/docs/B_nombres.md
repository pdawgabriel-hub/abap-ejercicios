# B. Convenciones de nombres

{% raw %}
| Objeto | Convención | Ejemplo |
|---|---|---|
| Tabla | `z<proy>_<nombre>` | `zgor_cli` |
| CDS interface | `ZI_<Proy><Nombre>` | `ZI_GorCliente` |
| CDS proyección | `ZC_<Proy><Nombre>` | `ZC_GorCliente` |
| Metadata extension | Igual que la proyección | `ZC_GorCliente` |
| Clase de comportamiento | `zbp_i_<nombre>` | `zbp_i_gorcliente` |
| Service Definition | `ZUI_<PROY>_<AREA>` | `ZUI_GOR_COMERCIAL` |
| Service Binding | `<Definition>_O4` | `ZUI_GOR_COMERCIAL_O4` |
| Clases de ejercicio | `ZCL_EJ_*` | `ZCL_EJ_PRECIOS` |
| Paquetes | `ZEJ`, `ZGOR`, `ZGOR_*` | `ZGOR_DDIC` |
