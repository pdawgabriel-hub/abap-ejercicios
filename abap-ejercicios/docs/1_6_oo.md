# 1.6. Clases y objetos (ABAP OO)

{% raw %}
> **Cómo ejecutar los ejemplos.** Los ejemplos muestran solo el **contenido del método `main`** de una clase ejecutable. Pégalos dentro de la plantilla de [1.1](1_1_classrun.html) (cambiando el nombre de la clase), activa con **Ctrl+F3** y ejecuta con **F9**.

La lógica reutilizable se escribe en **clases**: atributos (datos), métodos (acciones), visibilidad (`PUBLIC`/`PRIVATE`) y constructor. Se crean objetos con `NEW`. Las interfaces (`INTERFACE`) definen un contrato que varias clases pueden cumplir, y la herencia (`INHERITING FROM`) se usa con moderación.

Esta clase es un objeto **global** (otro objeto *ABAP Class*, distinto de tu clase de ejecución):

```abap
CLASS zcl_tl_vehiculo DEFINITION PUBLIC FINAL CREATE PUBLIC.
  PUBLIC SECTION.
    METHODS constructor
      IMPORTING iv_matricula TYPE string
                iv_anio      TYPE i.
    METHODS describir
      RETURNING VALUE(rv_texto) TYPE string.
    METHODS antiguedad
      IMPORTING iv_anio_actual TYPE i
      RETURNING VALUE(rv_anios) TYPE i.
  PRIVATE SECTION.
    DATA mv_matricula TYPE string.
    DATA mv_anio      TYPE i.
ENDCLASS.

CLASS zcl_tl_vehiculo IMPLEMENTATION.
  METHOD constructor.
    mv_matricula = iv_matricula.
    mv_anio      = iv_anio.
  ENDMETHOD.

  METHOD describir.
    rv_texto = |Vehiculo { mv_matricula } del { mv_anio }|.
  ENDMETHOD.

  METHOD antiguedad.
    rv_anios = iv_anio_actual - mv_anio.
  ENDMETHOD.
ENDCLASS.
```

Y así se usa desde `main`:

```abap
    DATA(lv_hoy)  = cl_abap_context_info=>get_system_date( ).
    DATA(lv_anio) = CONV i( lv_hoy(4) ).

    DATA(lo_coche) = NEW zcl_tl_vehiculo( iv_matricula = '1234ABC' iv_anio = 2015 ).
    out->write( lo_coche->describir( ) ).
    out->write( |Antiguedad: { lo_coche->antiguedad( lv_anio ) } anios| ).
```

> **Puente a Odoo.** Una clase ABAP es una clase Python: `constructor` ≈ `__init__`, atributos privados ≈ atributos con guion bajo. La diferencia: en RAP casi toda la lógica de negocio vive en clases, y los modelos son CDS.

## Comprueba tu solución automáticamente (opcional)

```abap
CLASS ltcl_presupuesto DEFINITION FINAL FOR TESTING
  DURATION SHORT RISK LEVEL HARMLESS.
  PRIVATE SECTION.
    DATA mo_cut TYPE REF TO zcl_ej_presupuesto.
    METHODS setup.
    METHODS subtotal_suma_lineas FOR TESTING.
    METHODS total_incluye_iva FOR TESTING.
    METHODS sin_lineas_es_cero FOR TESTING.
ENDCLASS.

CLASS ltcl_presupuesto IMPLEMENTATION.
  METHOD setup.
    mo_cut = NEW zcl_ej_presupuesto( iv_iva = CONV #( '0.21' ) ).
  ENDMETHOD.

  METHOD subtotal_suma_lineas.
    mo_cut->add_linea( iv_concepto = 'Pintura' iv_importe = CONV #( '100' ) ).
    mo_cut->add_linea( iv_concepto = 'Mano de obra' iv_importe = CONV #( '50' ) ).
    cl_abap_unit_assert=>assert_equals(
      act = mo_cut->subtotal( ) exp = CONV decfloat34( '150' ) ).
  ENDMETHOD.

  METHOD total_incluye_iva.
    mo_cut->add_linea( iv_concepto = 'Pintura' iv_importe = CONV #( '100' ) ).
    mo_cut->add_linea( iv_concepto = 'Mano de obra' iv_importe = CONV #( '50' ) ).
    cl_abap_unit_assert=>assert_equals(
      act = mo_cut->total( ) exp = CONV decfloat34( '181.5' ) ).
  ENDMETHOD.

  METHOD sin_lineas_es_cero.
    cl_abap_unit_assert=>assert_equals(
      act = mo_cut->total( ) exp = CONV decfloat34( '0' ) ).
  ENDMETHOD.
ENDCLASS.
```
