# 7.4. README y explicación en 5 minutos

{% raw %}
Un reclutador mira el README en menos de un minuto. Debe contener:

1. Qué es el proyecto y su origen (módulo Odoo `gestion_bd`).
2. Una captura de la app.
3. Tabla Odoo a SAP (entidades y conceptos).
4. Tecnologías: ABAP Cloud, RAP, CDS, OData V4, Fiori Elements, abapGit.
5. Cómo restaurarlo (`RESTAURAR.md`).
6. Lo que **no** está hecho (honestidad).

## Guion de 5 minutos

1. El problema (30 s).
2. Modelo de datos (1 min).
3. Demo de la app (2 min).
4. Una decisión de diseño explicada (1 min): por ejemplo UUID más número visible.
5. Qué mejorarías (30 s).

## Ejercicios

1. **Redacta el README** y pídele a alguien que lo lea en un minuto.
2. **Ensaya** el guion cronometrado.
