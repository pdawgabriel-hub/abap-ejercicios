# D. Planificación y hoja de ruta

{% raw %}
Con un trial de 90 días y la posibilidad de abrir otro, conviene dividir el trabajo en ciclos.

| Ciclo | Contenido | Repositorio |
|---|---|---|
| Antes del trial | Leer apuntes, diseñar el modelo y el mapa Odoo a SAP | proyecto (docs) |
| Ciclo 1 (90 d) | Bloques 0 a 5 (ejercicios) y fases 1 a 4 del proyecto | ambos |
| Ciclo 2 (90 d) | Fases 5 a 9 del proyecto | proyecto |

**Prueba temprana.** Abre el trial pronto para comprobar que todo funciona (semanas 2 a 3 del plan) y no descubrir un problema de acceso tarde. Pero ten en cuenta que los 90 días empiezan al registrarte: planifica para aprovecharlos.

## Ejercicios

1. **Fecha de registro.** Decide cuándo abrirás el trial y calcula tus fechas de copia.
2. **Pregunta pendiente.** Confirma con tu contacto en la empresa si el proyecto de prácticas es RAP / ABAP Cloud sobre S/4HANA.
