# 4.5. Proyecto: tu primera app

{% raw %}
Cierra el ciclo completo con Clientes y Obras: tabla, CDS, comportamiento, proyección, servicio y app.

## Criterio de «listo»

- [ ] Proyecciones y BDEF de proyección activas.
- [ ] Service Definition y Binding publicados.
- [ ] La Preview muestra la lista y el detalle de Clientes.
- [ ] Puedes crear un cliente desde la app y ver el número visible.
- [ ] Capturas guardadas en `docs/capturas/`.
- [ ] Push con abapGit («Fase 4: primera app Fiori»).

## Ejercicios

1. **Primera app.** Haz funcionar la app de Clientes.
2. **Captura.** Haz capturas de la lista, el detalle y un mensaje de validación.
3. **README.** Escribe 5 líneas en el README del proyecto explicando lo conseguido.
