# 5.4. Proyecto: control de calidad y copia

{% raw %}
## Criterio de «listo»

- [ ] ATC sin errores de prioridad 1-2.
- [ ] Repositorio enlazado y con un commit por semana.
- [ ] `RESTAURAR.md` probado con un pull a un paquete nuevo.
- [ ] Fecha de registro apuntada y recordatorios creados.

## Ejercicios

1. **Simulacro de restauración.** Anota cuánto tardas y qué pasos fallan.
2. **Revisión.** Pásale el ATC a tu paquete y arregla lo que aparezca.
